# KanisaHub

Church management for Seventh-day Adventist congregations. This is the public website for our information systems project at Strathmore University, Nairobi, built for DBT 1305 Web Application Development (Week 7 team assignment).

Authors: Heather Jeuls Nabawanda and Kerandi Nissy Treasure.

Pages: index, about, features, roles, events, giving, contact. All styling lives in `css/style.css`.
